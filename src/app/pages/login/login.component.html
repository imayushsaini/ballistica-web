help_outline How to get your Ballistica API Token

Option 1: Using Email & Password
  1. Visit ballistica.net and log in with your email and password.
  2. Click on API Keys → New API Key.
  3. Copy the API key and paste it in the field above.
Option 2: Via BombSquad Game (v1.7+)
  1. Open BombSquad (v1.7+) on your device.
  2. On the game's home page, click your Account Tag (top left), then click Manage Account (opens ballistica.net already signed in).
  3. On ballistica.net, click the Home logo (top left) → API Keys → New API Key.
  4. Copy the API key and paste it in the field above.
