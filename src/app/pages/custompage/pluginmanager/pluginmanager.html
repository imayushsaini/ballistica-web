Download BombSquad Plugin Manager

Introducing BombSquad Plugin Manager: Simplify game modding and access hundreds of community plugins, minigames, and utilities directly from inside your game.

The BombSquad Plugin Manager is a powerful, open-source modding utility designed specifically for the popular multiplayer party game BombSquad. This plugin manager serves as a convenient gateway to enhance your gaming experience by providing easy 1-click access to a wide range of community-created content, custom characters, game modes, maps, and server scripts.

Whether you are playing on Android, Windows, macOS, Linux, or VR headsets, the Plugin Manager brings effortless mod discovery and management straight to your game's settings menu.

build Installation Options & Guide

There are two recommended methods for installing the BombSquad Plugin Manager into your game:

1

Recommended Method: Direct Mods Directory

Download the plugin_manager.py file directly to your game's mods directory. Access your mods directory by opening BombSquad, navigating to Settings → Advanced → and clicking Show Mods Folder. Place plugin_manager.py in this folder and restart the game. This method supports automatic self-updates.

2

Cloud Workspace Method

Use the 1-Click Cloud Workspace Install button above to sync plugin_manager.py straight to your Ballistica cloud account. The game will automatically download and activate the script on your next launch or workspace sync.
