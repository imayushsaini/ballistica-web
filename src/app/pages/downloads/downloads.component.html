Download & Installation FAQ

Quick answers to common questions regarding game downloads, controller setup, and mods.

Custom mods and Python plugins are available in our Community Mods Repository. You can search over 500+ community-created minigames, custom characters, powerup packs, and server plugins. You can also use the Community Plugin Manager or connect your Ballistica API key in Workspaces to sync mods with 1 click!

For Windows, download the .zip package, extract the folder to your preferred location, and double-click BombSquad.exe to run. No complex installation is required. For Linux, extract the .tar.gz archive and execute the bombsquad binary.

Make sure both the device running BombSquad (PC, Mac, Android TV) and your phone are connected to the same Wi-Fi network. When you open the BombSquad Remote app, it will automatically search and connect to the running game within seconds.

- Windows: Inside the extracted game folder or under %APPDATA%/BombSquad/mods or workspace directory.
- Android: In Android/data/net.froemling.bombsquad/files/mods (or via Ballistica workspace sync).
- macOS: Under ~/Library/Application Support/BombSquad/mods.
- Linux: Under ~/.bombsquad/mods.
